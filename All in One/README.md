## ▶️ How to Compile and Run

You need a C compiler such as GCC.

1. Install GCC if it isn't already installed.
2. Open a terminal in the directory containing the C file.
3. Compile the program:

   ```bash
   gcc projects/guess-num.c -o guess-num
   ```

4. Run it on Windows:

   ```bash
   .\guess-num.exe
   ```

   On Linux or macOS:

   ```bash
   ./guess-num
   ```

Replace `projects/guess-num.c` with the path to another C source file to run a different project.
